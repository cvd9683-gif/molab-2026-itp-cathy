## Progress

- Built an ascii New York skyline at night, with stars, a crescent moon, and shooting stars, using the techniques from 02-Ascii-Play.
- Each piece of art is a text file in `Resources` (`sky`, `empire`, `chrysler`, `tall`, `short`).
- `load()` reads a file and splits it into lines, `combine()` glues two pieces side by side, line by line, and a for-loop glues all the buildings into one skyline.
- Open it in Xcode and press **Cmd-Shift-Y** to see the output in the console.
